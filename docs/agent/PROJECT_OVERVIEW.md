# 项目概览

## 研究主题

本项目研究 **VLM 引导的二维机器人抓取矩形检测**：使用预训练开放词汇视觉语言模型作为目标定位前端，再由几何方法或学习式方法预测二维机器人抓取矩形。

主研究仍是 Cornell RGB 二维抓取检测。项目另包含一个 PyBullet 补充仿真
验证：在固定场景中完成九点坐标反投影门控、五阶段真值姿态控制链验证
（运动-接近-闭合-抬升全部通过），以及两个感知后端（geometry/multi-head）
的完整物理抓取执行。感知静态与到达门控全部通过，但抬升因斜视相机导致的
XY 中心偏差（$24.67$--$26.62$\,mm）一致失败，根因已确认为单像素反投影
的三维中心偏差。

## 研究问题

核心问题是：预训练 VLM 的开放词汇目标定位能力能否在不针对 Cornell 数据集微调定位模型的情况下，提高二维抓取检测性能；在相同 VLM 定位前端下，传统几何后端与 CNN 学习式后端各有什么优势和局限。

## 数据集

项目使用 Cornell Grasping Dataset。每个样本通常包括 RGB 图像、深度图、点云，以及正负抓取矩形标注。当前实验使用 885 个样本；本地数据放在：

```text
data/raw/cornell/
```

数据集和生成的实验产物不提交到 Git。

## 对比方法

### 1. 传统计算机视觉基线

直接在完整 RGB 图像上执行颜色和亮度阈值分割，提取主要物体轮廓，并用最小面积旋转外接矩形产生抓取预测。该方法不使用 VLM，作为低成本、可解释的基准。

### 2. VLM 引导的几何实验流程

Grounding DINO 根据文本提示词产生目标定位框；OpenCV 几何后端只在定位区域中执行分割和轮廓分析，并根据物体几何估计抓取矩形。

### 3. VLM 引导的 CNN 实验流程

沿用相同的 Grounding DINO 定位前端，将目标裁剪区域输入轻量 CNN，回归抓取矩形的位置、尺寸和方向参数。该方法用于检验学习式抓取后端是否能改善位置精度和未见物体泛化。

## 评估方法

预测抓取矩形与 Cornell 正抓取标注逐一比较。只要存在一个标注同时满足以下条件，该预测即判定为成功：

```text
IoU >= 0.25
角度误差 <= 30°
```

主要报告成功率、平均最佳 IoU 和平均角度误差。CNN 结果同时区分单次实验与五次实验的均值和标准差，避免将单次结果与重复实验统计混淆。

## 主要发现

- VLM 定位将成功率从传统计算机视觉基线的 56.95% 提升至 VLM + 几何后端的 73.33%，是当前系统的主要性能增益来源。
- CNN 后端在完整数据集上取得更高的平均最佳 IoU。
- CNN 后端在固定目录 09–10 子集上优于几何后端；由于缺少权威物体实例映射，
  该结果不解释为一般性的未见物体泛化。
- 几何后端的平均角度误差更低，说明显式角度先验仍有价值。
- Grounding DINO 在当前提示词和数据设置下覆盖全部样本，因此后续改进重点应放在抓取后端。
- PyBullet 九点深度反投影门控为 `9/9`；18 个俯视候选全部通过 IK/FK，
  其中 12 个通过 `2 mm` 离散碰撞余量，最终 6/9 条输入选出候选。Duck
  三条输入均未通过环境余量，因此补充研究总门控保持 `false`。

## 范围与局限

- 当前结论主要来自 Cornell Grasping Dataset，尚不能直接代表真实机器人系统或更复杂场景。
- Cornell 主任务只预测二维抓取矩形；PyBullet 补充阶段只做静态 IK/FK 和
  离散状态碰撞审计，没有执行真实机械臂控制、连续轨迹或闭环抓取。
- Grounding DINO 的全覆盖结果不等同于定位框完美；定位误差仍可能影响后端。
- CNN 的重复实验统计降低了随机划分或初始化造成的偶然性，但仍需要更多数据集验证。
- 单个固定仿真场景和 41 状态离散插值不能证明连续路径安全、稳定接触、闭合
  或抬升成功，也不能作为物理抓取成功率。
