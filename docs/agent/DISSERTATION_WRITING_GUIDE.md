# 毕业论文写作结构与字数要求

> 本文档用于指导当前 MSc 毕业论文写作。以下字数为目标范围，最终以学院和
> 导师的正式要求为准。预计全文核心章节约 9,300–12,400 字。

## Abstract 摘要（300–400 字）

摘要应简洁概括整篇论文，使读者不阅读正文也能了解研究内容。

1. **Research background and question**
   - 介绍研究背景和需要解决的问题。
   - 明确核心研究问题。
2. **Methodology**
   - 概括所用数据、实验流程和评价方法。
3. **Key findings**
   - 给出最重要且已经验证的研究发现。
4. **Implications**
   - 说明研究结果的理论意义或实际价值。
5. **Limitations**
   - 简要说明研究范围和主要限制。

摘要应在其他章节完成后最后撰写，避免摘要与正文数字或结论不一致。

## Introduction 引言（约 1,000 字）

引言负责说明“为什么要研究这个问题”以及“论文准备如何回答它”。

1. **Research question and why**
   - 明确研究问题。
   - 解释该问题为什么值得研究。
2. **Research objectives**
   - 给出总体研究目标。
   - 列出可以验证的具体任务。
3. **Research significance**
   - 说明研究的学术价值、工程价值和实际意义。
4. **Dissertation structure**
   - 简要介绍各章节的内容和逻辑关系。

引言不应提前详细讨论实验数字，也不应重复 Literature Review 的文献分析。

## Literature Review 文献综述（3,000–4,000 字）

Literature Review 是体现研究价值、研究深度、逻辑思考和 critical thinking 的
核心章节。

1. **归纳、总结和分析前人研究**
   - 按研究主题或技术发展组织文献，而不是逐篇罗列。
   - 选择 4–5 篇与本项目最相关的论文进行重点分析。
   - 其他文献用于补充技术发展和研究背景。
2. **批判性分析不足与漏洞**
   - 比较不同方法的输入模态、数据划分、输出形式和评价指标。
   - 分析方法假设、数据依赖、泛化能力和实验可比性。
   - 避免只根据论文报告的最高准确率形成简单排行榜。
3. **确定 Literature Gap**
   - 从前人研究的限制中提出仍未解决的问题。
   - Literature Gap 必须能够自然引出本论文的研究问题。
4. **明确研究目的**
   - 说明本项目如何针对 Literature Gap 开展受控实验。
   - 研究目的必须与引言中的 Research Questions 对应。

结合本项目，重点文献可围绕 Cornell 抓取矩形、CNN 直接回归、密集抓取预测、
开放词汇定位和语言驱动抓取展开。RGB、RGB-D、image-wise、object-wise、
密集输出和物理抓取结果之间只能在评价条件一致时进行直接比较。

## Methodology 方法论（1,000–2,000 字）

Methodology 负责解释研究是如何实施的，以及为什么选择这些方法。

1. **研究方法及选择原因**
   - 说明方法如何帮助回答研究问题。
   - 分析所选方法的优点和缺点。
   - 解释为什么选择该方法，而不是其他可能方案。
2. **Research design**
   - 介绍数据集、数据准备和实验划分。
   - 说明实验流程、模型训练、评价指标和结果审计方法。
   - 说明各实验流程之间如何形成受控比较。
3. **方法限制及处理方式**
   - 说明数据、模型、输入模态和评价协议的限制。
   - 解释如何通过确定性设置、交叉验证、共同 manifest 和结果溯源降低风险。
4. **Research Ethics**
   - 说明数据来源、数据许可证和合理使用。
   - 确保引用论文、代码和预训练模型时明确标注出处。
   - 说明实验结果不被夸大或错误解释。

本项目不包含问卷、人类参与者或私人数据，因此保密、自愿参与和知情同意通常
不适用。Ethics 应重点讨论公开数据使用、学术引用、外部代码来源、预训练模型、
计算资源和结果可复现性。

## Findings / Results 发现与结果（3,000–4,000 字）

Findings 应直接回答 Research Questions。建议充分使用 figure 和 table 展示
研究发现，并在正文中解释其含义。

1. **详细描述和分析案例**
   - 展示具有代表性的成功、失败和边界案例。
   - 区分观察到的结果与可能的原因，避免把推测写成结论。
2. **展示并分析数据**
   - 报告成功率、IoU、角度误差、均值和标准差。
   - 明确区分固定目录、五随机种子和 image-wise 五折结果。
   - 使用表格和图形支持文字分析。
3. **从数据得出结论**
   - 将发现与每个 Research Question 对应。
   - 比较不同方法的优势、局限和互补性。
   - 说明哪些结论可以推广，哪些只能用于当前实验条件。

所有论文数字必须能够追溯到已经保存并审计的 CSV 或 JSON。Image-wise 结果
不得解释为 object-wise 未见物体泛化，Cornell rectangle success 也不得等同
于真实机器人抓取成功。

## Conclusion 结论（约 1,000 字）

Conclusion 应回到论文最初提出的问题，而不是简单重复 Results。

1. 简要总结研究背景、方法和最重要的发现。
2. 逐条回答 Research Questions。
3. 总结研究贡献和实际意义。
4. 说明研究限制。
5. 提出合理的 Future Work，例如 object-wise 元数据恢复、深度融合、真实机器人
   验证或更强的抓取后端。

结论不得加入正文中没有验证过的新实验或新主张。

## 推荐写作顺序

1. Literature Review
2. Introduction
3. Methodology
4. Findings / Results
5. Conclusion
6. Abstract

先完成 Literature Review 可以更清楚地确定研究缺口；Abstract 最后撰写可以
确保研究问题、方法、数字、结论和限制与完整论文一致。
