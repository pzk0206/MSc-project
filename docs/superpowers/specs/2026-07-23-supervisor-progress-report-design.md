# 导师项目进展汇报 PDF 设计

日期：2026-07-23  
汇报人：Pang Zhenkun  
项目：开放词汇视觉语言模型用于二维机器人抓取检测的评估

## 目标

生成一份适合与导师当面讨论的三页中文 PDF。汇报应在较短时间内说明整个项目已经完成的工作、主要实验结果、当前结论以及下一步安排，不展开实现代码和训练细节。

## 内容结构

### 第 1 页：项目概览

- 研究问题：开放词汇 VLM 定位能否改善二维机器人抓取矩形检测。
- 实验对象：Cornell Grasping Dataset，共 885 个样本。
- 评估标准：IoU 不低于 0.25，且角度误差不超过 30°。
- 三条对比流程：
  1. 传统计算机视觉基线；
  2. Grounding DINO 定位与几何抓取后端；
  3. Grounding DINO 定位与轻量 CNN 抓取后端。

### 第 2 页：实验结果

- 用紧凑表格比较三种方法的成功率、平均最佳 IoU 和平均角度误差。
- 单独强调未见物体测试集上的几何后端与 CNN 后端结果。
- 给出三个结论：
  - VLM 定位带来最大的成功率提升；
  - CNN 后端具有更好的位置、尺寸预测和未见物体泛化；
  - 几何后端的角度估计更准确。

### 第 3 页：当前状态与下一步

- 已完成：三条实验流程、五次 CNN 重复实验、失败案例分析和整体对比。
- 局限：仅在 Cornell 数据集进行离线二维评估，未进行真实机器人闭环实验。
- 下一步：完成论文主体、整理结果图表、补充逐样本分析；时间允许时探索几何角度先验与 CNN 位置回归结合。
- 简短列出 Grounding DINO 和 GG-CNN 两项关键论文依据。

## 视觉设计

- A4 横向三页，适合屏幕展示，也可直接打印。
- 中文白底，使用深蓝色标题、青绿色重点和少量橙色提示。
- 每页只保留一个中心信息，使用卡片、流程箭头、指标表和短句。
- 避免大段文字、复杂背景、代码片段和过多文献。
- 页脚显示项目简称、日期和页码。

## 数据要求

- 只使用项目文档中已经验证的指标。
- 五次重复实验以均值和标准差呈现，不与单次实验混淆。
- Grounding DINO 的 885/885 定位结果描述为当前提示词和实验设置下的样本覆盖，不表述为定位框完全准确。

## 验收标准

- PDF 正好三页，中文字符正常显示。
- 所有内容在页面边界内，无重叠、截断或字号过小。
- 核心实验数字与 `docs/agent/CURRENT_STATUS.md` 一致。
- 生成文件保存在 `docs/reporting/`，同时保留可编辑源文件。
