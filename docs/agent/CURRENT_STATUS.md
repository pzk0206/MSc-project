# 项目当前状态

> AI 任务入口：开始项目工作前先阅读本文件。

最后更新：2026-07-27

## 当前阶段

三条核心 Cornell 实验流程、确定性单头/多头五随机种子对照以及 image-wise
五折均已完成。两个架构的 885 条合并预测和成对比较已经独立审计。中文论文
初稿、数字、引用和 PDF 已验证。导师建议的 PyBullet 第一阶段感知 pilot
及固定三物体目标选择研究均已完成真实 GPU 验证。三条明确 prompt 通过当前
二维感知门控；当前重心是把仿真结果写成有边界的可行性证据，并在需要时进入
深度反投影和机械臂执行设计，而不是把二维结果称为物理抓取成功。

## 已完成的实验流程

1. **传统计算机视觉基线**
   - 在整幅 RGB 图像上进行颜色/亮度阈值分割。
   - 提取轮廓并计算最小面积旋转外接矩形。
   - 使用 Cornell 抓取矩形指标评估预测抓取框。
2. **VLM 引导的几何实验流程**
   - 使用 Grounding DINO 和文本提示词完成目标定位。
   - 在定位框内运行 OpenCV 几何抓取后端。
3. **VLM 引导的 CNN 实验流程**
   - 使用 Grounding DINO 产生目标裁剪区域。
   - 使用轻量 CNN 回归抓取矩形参数。
   - 支持单头、多头、单次实验和五次重复实验汇总。
4. **PyBullet 虚拟相机感知 pilot**
   - DIRECT 模式加载桌面、Franka Panda 和 `duck_vhacd.urdf`。
   - 固定虚拟相机生成 RGB、米制深度和 segmentation。
   - RGB 接入现有 Grounding DINO、几何和 CNN 抓取后端接口。
   - 保存定位、二维抓取预测和完整元数据；明确
     `physical_grasp_executed: false`。
   - 第一阶段不包括坐标回投、逆运动学、碰撞规划或夹爪执行。

### Image-wise 五折正式结果

正式 manifest 使用 seed 42，覆盖 885 个唯一 sample ID。每折为 566 个训练、
142 个验证和 177 个测试样本；五个测试集合两两互斥。JSON SHA-256 为

| 架构 | 成功数 | Pooled 成功率 | 平均 IoU | 平均角度误差 |
|---|---:|---:|---:|---:|
| 单头 | 635 / 885 | 71.75% | 0.4390 | 17.74° |
| 多头 | 647 / 885 | **73.11%** | **0.4580** | **17.40°** |

数值有限，且每折最佳验证损失与保存历史的最小值一致。

Object-wise 需要图像到物体实例的权威映射；当前数据和已检查来源没有提供
可审计映射，`01`–`10` 也不是 object ID，因此不生成 object-wise 结果。

### PyBullet 第一阶段验证

- PyBullet `3.2.7`、API `202010061` 已安装到 `msc-grasp` 环境。
- 沙箱内无法访问 GPU，`torch.cuda.is_available()` 为 `False`；同一 Conda
  环境在沙箱外验证为 `True`，设备为 `NVIDIA GeForce GTX 1650 Ti`。
- 当前共有 38 项 simulation 测试；完整项目回归为 `70 passed`。
- DIRECT + TinyRenderer + CUDA 的真实 geometry pilot 成功生成 640×480
  RGB、深度、segmentation、定位、预测和 metadata。
- 默认 generic prompt `small object` 返回了可见框，但人工检查确认它框住
  Panda 末端而非黄色小鸭：box `[323, 68, 450, 150]`，score `0.5985`。
- 只改变 prompt 为 `yellow rubber duck` 后，Grounding DINO 正确框住小鸭：
  box `[318, 208, 374, 273]`，score `0.6985`；几何后端输出有限合法的二维
  抓取框。该单案例仅支持系统可行性和 prompt 歧义分析，不支持成功率结论。
- 固定多物体场景同时包含黄色鸭、红色方块、绿色球体和 Panda distractor；
  一次渲染、一次模型加载后依次运行三条明确 prompt 和 `small object`。
- 三条主 prompt 均唯一匹配指定目标：鸭 IoU `0.8597`、方块 `0.8717`、
  球体 `0.8485`，目标选择率为 `3/3`，平均指定目标 IoU `0.8600`。
- 三个几何抓取中心均位于各自 segmentation mask 内；人工检查同时发现抓取
  框宽度普遍超出物体轮廓，因此不能据此声称夹爪闭合或物理抓取成功。
- generic prompt `small object` 选择红色方块，box
  `[297, 189, 344, 245]`、score `0.5933`，不计入三目标成功率。
- 首次真实运行暴露 Panda 基座与桌体初始穿透，球体被动力学求解器弹出画面；
  将固定研究场景的 Panda 基座放到桌面高度后，初始接触为零且四个评价实体
  保持可见。该问题已有专门回归测试。
- 真实产物位于
  `data/processed/pybullet/multi_object_study/`；metadata 保持
  `segmentation_used_as_model_input: false` 和
  `physical_grasp_executed: false`。

## 已确认的主要发现

- VLM 定位前端带来的提升最大：成功率从 56.95% 提升至 73.33%。
- CNN 后端在固定的 85 个测试样本上高于几何后端；由于目录 09–10 的物体
  构成和难度无法确认与其他分组可比，该结果不解释为一般性的未见物体泛化。
- CNN 后端的平均 IoU 更高，位置和尺寸预测更准确。
- 几何后端的角度误差更低，说明“物体长轴的垂直方向”仍是有效的抓取角度先验。
- 当前主要瓶颈已从目标定位转移到抓取框后端。
- 数据划分审计发现传统 CV 在测试子集上的成功率为 74.12%，明显高于训练
  子集的 53.17%；这进一步要求谨慎解释测试结果。
- 固定 85 样本的逐样本交叉比较为：两者都成功 52、仅 CNN 成功 16、仅几何
  成功 12、两者都失败 5，说明两个后端具有可量化的互补性。

### 已确认的正式实验决策

1. 修复后的单头和多头 seeds 42–46 正式对照已经完成并审计。
2. 使用共同 manifest 运行 image-wise 五折；训练 seed 固定为 42，每个 fold
   分别保存模型、历史、177 条测试预测和 summary。
3. Object-wise 只有在获得权威实例映射后才实现；当前保持元数据阻塞状态，
   不使用目录或视觉相似度推断 object ID。
4. 五个随机种子与五折交叉验证分开报告；前者描述训练随机性，后者描述
   image-wise 划分变化。
5. 保留当前 `01–06/07–08/09–10` 固定目录结果，用于后端逐样本比较和失败
   分析，但不再称为标准 Cornell object-wise protocol。
6. RGB-D 不加入本月正式主实验。当前研究继续限定为 Grounding DINO RGB
   crop 下的轻量抓取后端比较；深度融合写入局限与未来工作，避免同时扩大
   输入模态、网络结构和评价协议。
7. 正式单头/多头实验启用严格确定性设置。仅调用随机种子但未关闭 CUDA
   非确定性的批次保留为诊断记录，不进入最终公平对照。
8. PyBullet 第一阶段只作为从 Cornell 静态图像到机器人式虚拟相机输入的
   系统集成与失败模式 pilot；不得称为真实抓取或仿真抓取成功率实验。
9. 多物体研究的 segmentation 只作事后真值评价。`0.25` 是固定 pilot 的
   目标框 IoU 工程门槛，不是 Cornell 抓取矩形指标；generic prompt 只作
   诊断，不进入三目标成功率。
