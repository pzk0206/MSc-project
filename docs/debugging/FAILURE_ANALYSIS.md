## 2. 失败模式分类

236 个失败样本可以分为三类：

| 失败模式 | 数量 | 占比 | 含义 |
|---|---|---|---|
| 仅 IoU 失败 (角度 ≤ 30°) | 126 | 53.4% | 抓取方向正确，但位置/尺寸不够吻合 |
| 仅角度失败 (IoU ≥ 0.25) | 45 | 19.1% | 找到了正确位置，但抓取方向估计错误 |
| 两者都失败 | 65 | 27.5% | 位置和方向都不对 |

### 关键发现

- **126 个样本 (53%) 角度已经正确，纯粹是几何后端无法生成合适的位置/尺寸**
- 这说明：如果能让 CNN 后端在这些样本上学到更准确的 center/width/height，仅这一类就能让成功率从 73.3% 提升到 87.6%
- 45 个样本角度错误但位置对，可能来自物体长轴/短轴方向的启发式规则在某些形状上失效

## 7. 指标层面诊断与原因假设

以下三类是根据 IoU 和角度阈值得到的**观测分类**，不能单凭数值自动推断真实
原因。尤其是 VLM “检测率 100%”只表示每张图返回了 box，不表示每个 box 都
准确或足够紧。早期表格中的“可能原因”应视为待验证假设，而不是逐图确认的
统一结论。

基于以上数据，VLM 引导的几何实验流程失败主要有以下根本原因：

### 7.1 几何后端的固有局限（约占失败的 53%）

- 126 个样本角度正确但 IoU 不足
- 这说明 OpenCV 基于颜色/亮度的 mask 分割 + minAreaRect 的方法，即使知道了物体位置，生成的抓取矩形的中心、宽度、高度仍然不够准确
- 原因是：轮廓形状不完全等于最佳抓取区域；物体表面的纹理、阴影会改变轮廓边界

### 7.2 抓取方向启发式规则的失效（约占失败的 19%）

- 45 个样本 IoU 达标但方向错误
- 当前规则：抓取方向 = 物体长轴方向 + 90°（即横跨物体窄侧）
- 这个规则在非规则形状、多分支物体、或抓取标注不沿物体主轴时失效

### 7.3 复合失败（约占失败的 28%）

- 65 个样本两者都失败
- 这些是几何后端最难处理的样本：位置、大小、方向同时出错

### 7.4 VLM 引导流程退化（9 个样本）

- 这 9 个样本 VLM 定位后的几何抓取反而不如整图 CV baseline
- 指标本身不能区分 VLM box、局部 mask 和后端尺寸规则各自的影响；裁剪过紧、
  覆盖过宽或局部轮廓选择错误都只是待逐样本验证的可能解释

## 8. 对 CNN 后端的启示

1. **优先级最高**：解决 126 个 '仅 IoU 失败' 样本——CNN 应该能直接学习从 VLM crop 回归更准确的 center/width/height
2. **角度学习**：45 个角度失败样本说明 sin(2θ)/cos(2θ) 的角度回归比几何规则更灵活
3. **难例处理**：65 个双失败样本是检验 CNN backend 上限的关键测试集
4. **VLM box 扩展**：9 个退化案例提示 expand_ratio 可能需要调大，或 CNN 需要接受比 VLM box 更大的输入区域

## 9. 可写入论文的表述草稿

```text
对 Cornell 数据集上 VLM 引导的几何实验流程进行失败分析后，可以区分出三种失败模式。在 236 个失败样本中，126 个（53%）虽然抓取方向正确，但仅因 IoU 不足而失败，说明即使方向正确，手工几何后端仍无法准确生成抓取中心和尺寸。另有 45 个（19%）仅因角度误差超过 30 度而失败，表明使用物体长轴垂直方向的启发式规则对不规则形状物体并不可靠。其余 65 个样本（28%）同时不满足两个条件。只有 9 个在 VLM 引导流程中失败的样本能够被传统计算机视觉基线正确预测，说明基于 VLM 的定位很少导致性能退化。这些结果支持使用学习式抓取后端直接从 VLM 裁剪区域预测抓取参数，从而绕过手工几何规则的局限。
```

## 10. 固定测试子集的 CNN/几何交叉分析

日期：2026-07-24

### 10.1 四类结果

| 类别 | 数量 | 可直接支持的结论 |
|---|---:|---|
| 两者都成功 | 52 | 两个后端在多数固定测试样本上达成一致 |
| 仅 CNN 成功 | 16 | CNN 能解决一部分几何后端失败 |
| 仅几何成功 | 12 | 几何先验仍能解决一部分 CNN 失败 |
| 两者都失败 | 5 | 共享 VLM crop 不能消除所有后端错误 |

固定 85 样本中有 28 个产生互斥成功结果，因此不能把一个后端描述为在所有
情况下支配另一个。以下代表案例由脚本按指标差异固定选择，不是手工挑选的
“最好看”样本。

### 10.2 仅 CNN 成功的代表案例

| 样本 | 几何 IoU / 角度误差 | CNN IoU / 角度误差 | 观察到的现象 | 可能解释 |
|---|---:|---:|---|---|
| `10/pcd1008` | 0.179 / 12.44° | 0.616 / 7.15° | 两者角度均达标，CNN IoU 明显更高 | 几何短边尺寸规则可能低估抓取范围 |
| `10/pcd1013` | 0.206 / 6.90° | 0.627 / 11.12° | 失败差异主要来自 IoU | CNN 学到的中心/尺寸更接近该标注 |
| `10/pcd1005` | 0.154 / 6.82° | 0.516 / 20.46° | CNN 虽角度较差但仍达标，空间匹配更好 | 学习式尺寸回归可能补偿固定下限 |
| `10/pcd1012` | 0.145 / 4.15° | 0.489 / 29.44° | CNN 接近角度阈值，但 IoU 足以成功 | 成功来自空间预测，不表示方向更稳定 |

“几何规则导致尺寸偏小”与这些数值和图像一致，但仍是解释性假设；要确认
因果关系，需要只替换 width/height 规则的消融实验。

### 10.3 仅几何成功的代表案例

| 样本 | 几何 IoU / 角度误差 | CNN IoU / 角度误差 | 观察到的现象 |
|---|---:|---:|---|
| `10/pcd1003` | 0.477 / 8.62° | 0.127 / 5.18° | CNN 为位置/尺寸失败，非角度失败 |
| `10/pcd1001` | 0.637 / 21.66° | 0.370 / 53.31° | CNN 主要因角度失败 |
| `09/pcd0945` | 0.674 / 11.65° | 0.456 / 32.13° | CNN 仅略超过角度阈值 |
| `09/pcd0947` | 0.570 / 12.11° | 0.359 / 68.89° | CNN 出现严重角度误差 |

这四个案例至少包含两种不同现象，不能统一归因为“CNN 角度差”。其中三个
支持几何长轴先验在方向上的价值，`10/pcd1003` 则是独立的空间回归错误。

### 10.4 两者都失败的代表案例

| 样本 | 几何 IoU / 角度误差 | CNN IoU / 角度误差 | 观察到的现象 | 可能解释 |
|---|---:|---:|---|---|
| `10/pcd1000` | 0.000 / 25.94° | 0.000 / 27.00° | VLM box 接近整幅图，两个后端 IoU 均为零 | 上游定位过宽可能是共同影响因素 |
| `09/pcd0918` | 0.237 / 3.11° | 0.216 / 2.56° | 两者方向准确，IoU 均略低于阈值 | 边界尺寸/位置误差 |
| `10/pcd1016` | 0.179 / 84.41° | 0.503 / 86.62° | CNN IoU 达标但两者方向严重错误 | 主要为方向失败 |
| `10/pcd1024` | 0.344 / 75.45° | 0.585 / 74.92° | 两者 IoU 达标但方向严重错误 | 共享的方向歧义或标注差异 |

这里唯一能由保存数据直接确认的是 box 范围、IoU 和角度误差。“定位错误”、
“物体方向歧义”或“标注差异”需要进一步查看原始深度、标注和替代 prompt，
因此在论文中使用“可能”而不是确定性因果措辞。
