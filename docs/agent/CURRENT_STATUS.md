# 项目当前状态

> AI 任务入口：开始项目工作前先阅读本文件。

最后更新：2026-07-24

## 当前阶段

三条核心实验流程已完成，并在 Cornell Grasping Dataset 的 885 个样本上完成评估。当前项目重心已从基础实验实现转向毕业论文写作、结果整理和补充分析。

## 已完成的实验流程

1. **传统计算机视觉基线**
   - 在整幅 RGB 图像上进行颜色/亮度阈值分割。
   - 提取轮廓并计算最小面积旋转外接矩形。
   - 使用 Cornell 抓取矩形指标评估预测抓取框。
2. **VLM 引导的几何实验流程**
   - 使用 Grounding DINO 和文本提示词完成目标定位。
   - 在定位框内运行 OpenCV 几何抓取后端。
3. **VLM 引导的 CNN 实验流程**
   - 使用 Grounding DINO 产生目标裁剪区域。
   - 使用轻量 CNN 回归抓取矩形参数。
   - 支持单头、多头、单次实验和五次重复实验汇总。

## 最新已验证结果

### 完整 Cornell 数据集（885 个样本）

| 方法 | 成功数 | 成功率 | 平均最佳 IoU | 平均角度误差 |
|---|---:|---:|---:|---:|
| 传统计算机视觉基线 | 504 / 885 | 56.95% | 0.3360 | 29.62° |
| VLM + 几何后端 | 649 / 885 | 73.33% | 0.4182 | **14.81°** |
| VLM + CNN 后端（五次实验均值 ± 标准差） | — | 74.51% ± 1.38% | 0.4510 ± 0.0081 | 16.49° ± 0.72° |

原始 73.11% 单次实验的独立 JSON/CSV 已被后续多轮运行覆盖，因此不进入
论文主表。当前保存的逐样本 CNN 预测来自五次实验最后一轮（seed 46）。
旧单头目录继续作为历史证据保留；其中五轮聚合成功率、IoU 和角度指标仍可
追溯，但旧 `per_run.best_val_loss` 字段无效，且各 seed 的权重、历史和逐样本
CSV 没有完整隔离保存。最终单头基线将使用修复后的代码在新目录重新运行，
不覆盖这些历史产物。

### 固定测试子集（Cornell 目录 09–10，共 85 个样本）

| 方法 | 测试集成功率 |
|---|---:|
| VLM + 几何后端 | 75.3%（64 / 85） |
| VLM + CNN 后端（最后一轮，seed 46） | 80.0%（68 / 85） |
| VLM + CNN 后端（五次实验均值 ± 标准差） | **82.35% ± 4.53%** |

Grounding DINO 使用提示词 `small object`，在当前实验中成功定位全部 885 个 Cornell 样本。

### 多头 CNN 可行性门控（seed 42）

多头模型使用共享卷积主干及中心、尺寸、方向三个回归头。2026-07-24 的单次
门控实验在第 43 个 epoch 早停，最佳验证损失为 0.213861；全部损失分项均为
有限值。完整 885 样本成功率为 77.18%，平均 IoU 为 0.4630，平均角度误差为
15.63°；固定 85 样本测试集成功率为 82.35%，平均 IoU 为 0.5056，平均角度
误差为 18.58°。

该结果仅用于确认结构和实验流程可行，尚未替代上方五次单头实验主结果。
885 个输出框均已验证中心在图像内、宽高为正。下一步需要完成多头模型五次
独立运行，才能比较稳定性并决定是否写入论文主结果。

## 已确认的主要发现

- VLM 定位前端带来的提升最大：成功率从 56.95% 提升至 73.33%。
- CNN 后端在固定的 85 个测试样本上高于几何后端；由于目录 09–10 的物体
  构成和难度无法确认与其他分组可比，该结果不解释为一般性的未见物体泛化。
- CNN 后端的平均 IoU 更高，位置和尺寸预测更准确。
- 几何后端的角度误差更低，说明“物体长轴的垂直方向”仍是有效的抓取角度先验。
- 当前主要瓶颈已从目标定位转移到抓取框后端。
- 数据划分审计发现传统 CV 在测试子集上的成功率为 74.12%，明显高于训练
  子集的 53.17%；这进一步要求谨慎解释测试结果。
- 固定 85 样本的逐样本交叉比较为：两者都成功 52、仅 CNN 成功 16、仅几何
  成功 12、两者都失败 5，说明两个后端具有可量化的互补性。

### 已确认的正式实验决策

1. 在独立输出目录中重跑修复后的单头 CNN，使用 seeds 42–46；每个 seed
   分别保存模型权重、训练历史和真实最佳验证损失。
2. 使用完全相同的 seeds 42–46 正式运行多头 CNN，并与重跑后的单头结果
   比较均值、标准差和逐项指标。
3. 在能够可靠恢复 Cornell 物体实例分组的前提下，优先增加 object-wise
   五折交叉验证；同一物体的全部视角不得跨 fold。这是支持未见物体结论的
   主要标准化实验。
4. object-wise 完成后增加 image-wise 五折，用于提高与 Cornell 文献结果表
   的有限可比性。五个随机种子与五折交叉验证必须分开报告。
5. 保留当前 `01–06/07–08/09–10` 固定目录结果，用于后端逐样本比较和失败
   分析，但不再称为标准 Cornell object-wise protocol。
6. RGB-D 不加入本月正式主实验。当前研究继续限定为 Grounding DINO RGB
   crop 下的轻量抓取后端比较；深度融合写入局限与未来工作，避免同时扩大
   输入模态、网络结构和评价协议。
