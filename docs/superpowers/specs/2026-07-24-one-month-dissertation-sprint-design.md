# 一个月毕业论文冲刺设计

日期：2026-07-24

计划周期：2026-07-24 至 2026-08-23

提交时间假设：约 2026-08-24；若学校正式截止日期不同，所有阶段按相同提前量整体平移。

## 1. 目标

在一个月内完成一篇证据链完整、结论谨慎且能够回应 2026-07-23 导师反馈的 MSc 毕业论文，并在不危及提交质量的前提下完成一个范围受控的网络扩展。

最终论文需要清楚回答：

1. Grounding DINO 定位前端相对整图传统视觉基线带来了什么变化；
2. 在相同 VLM 定位前端下，几何后端和 CNN 后端各自有什么优势；
3. 目录 09–10 的结果能否被合理解释为未见物体泛化；
4. 当前 CNN 的结构、文献依据和自主工程选择分别是什么；
5. 当前结果与现代二维抓取文献有什么关系，以及为什么部分数字不能直接横向比较；
6. 一个受控的现代化扩展是否改善了性能、稳定性或可解释性。

## 2. 范围

### 2.1 必须完成

- 审计 Cornell 目录 01–06、07–08、09–10 的物体类型和难度可比性；
- 在固定的 85 个测试样本上公平比较几何后端和 CNN 后端；
- 制作三组数据样例图、CNN 结构图、最终结果表和失败案例图；
- 建立现代二维抓取文献比较表，记录输入、数据划分、指标和结果；
- 解释当前 CNN 的层级结构、参数输出和设计依据；
- 完成论文 Introduction、Literature Review、Methodology、Results、Discussion、Conclusion 和 Abstract；
- 记录关键实验的环境、配置、随机种子和复现命令；
- 完成一个主要技术扩展的可行性判断，并在可行时完成正式对照实验；
- 在提交前从最终 LaTeX 源文件生成并逐页检查 PDF。

### 2.2 主要技术扩展

首选扩展为共享特征提取器上的多头 CNN：

```text
共享轻量特征提取器
├── centre head：cx, cy
├── size head：w, h
└── orientation head：sin(2θ), cos(2θ)
```

该扩展保持现有输入、数据划分和 Cornell 评价协议不变，使结果能够与当前单头 CNN 直接比较。方向头可加入单位圆约束，以减少方向向量模长不稳定的问题。

正式实验至少比较：

- VLM + 几何后端；
- VLM + 当前单头 CNN；
- VLM + 多头 CNN。

多头 CNN 使用与当前 CNN 一致的五次重复实验协议，报告成功率、平均最佳 IoU、平均角度误差以及均值和标准差。即使没有性能提升，结果仍作为结构消融和局限分析报告，不通过持续调参隐藏负结果。

### 2.3 回退扩展

多头 CNN 仅获得两个工作日的可行性窗口。如果两天后仍不能稳定完成训练、推理和现有评价流程，则停止该方向，不继续扩大网络搜索。回退工作选择逐样本 CNN 失败分析，并在时间允许时增加 Grad-CAM 或特征热图。

回退分析至少输出：

- CNN 成功而几何后端失败的样本；
- 几何后端成功而 CNN 失败的样本；
- 两种方法同时失败的样本；
- 按 IoU 失败、角度失败和复合失败划分的数量与代表图像。

### 2.4 可选范围

PyBullet 只作为最后阶段的单日可行性实验。只有在完整论文初稿和技术扩展均已完成后，才尝试：

```text
虚拟相机 RGB 图像
→ 当前模型预测
→ 在图像上叠加抓取矩形
```

机械臂逆运动学、夹爪执行、闭环重新估计和抓取成功率不属于本月承诺范围。

## 3. 明确不做

- 不同时开展多头 CNN、预训练骨干、U-Net 和密集抓取图；
- 不更改核心数据划分来追求更高测试数字；
- 不把目录 09–10 的结果直接表述为一般性的未见物体泛化能力；
- 不承诺 Jacquard、真实机器人或完整 PyBullet 抓取实验；
- 不在实验冻结日期之后增加新模型、新数据集或大规模超参数搜索；
- 不把基础 CNN 或多头拆分声称为原创抓取架构。

## 5. 每日工作方式

默认每周工作六天，每天分为三个工作块：

1. 上午：执行当天唯一的主要分析、实验或章节写作任务；
2. 下午：把当天证据立即转化为论文文字、表格或图；
3. 晚间：核对输出、记录来源并确定第二天的一个首要任务。

每个工作日结束时应留下可检查的产物，例如一个章节、一张最终图、一张数据表或一个验证过的实验结果，而不是只记录“继续研究”。

## 6. 决策门槛

### 6.1 泛化结论

- 如果目录 09–10 在形状和难度上明显更简单，只报告“固定测试子集表现”；
- 如果三个分组具有基本可比性，仍使用“结果支持有限的未见物体泛化”而非“证明一般泛化”；
- 无论审计结果如何，都保留测试集规模小和 Cornell-only 的局限。

### 6.2 多头 CNN

- 两天内形成稳定端到端流程：进入五次重复实验；
- 两天后仍存在训练、输出或评估阻塞：立即回退；
- 五次结果没有提升：作为消融结果报告，不再追加大规模调参。

### 6.3 PyBullet

只有同时满足以下条件才开始：

- 完整论文初稿已生成；
- 所有必需图表已经进入论文；
- 技术扩展已经结束；
- 距提交至少还有五天。

任一条件不满足时，取消 PyBullet。

## 7. 质量控制

- 实验结果只有在实际命令输出验证后才能写入论文；
- 同一指标使用一致的小数位和统计口径；
- 单次实验与五次均值不得混写；
- 85 样本测试结果不得与 885 样本全量结果作不加说明的直接比较；
- 文献结果必须同时记录数据划分、输入模态和评价协议；
- “检测到框”与“定位框准确”必须明确区分；
- Results 主要描述事实，Discussion 负责解释原因和意义；
- 每个主要结论至少对应一个表格、图像或统计结果。

## 8. 成功标准

本月计划成功不以击败 SOTA 或完成机械臂抓取为条件，而以以下结果为准：

1. 论文主体按期完成并通过格式、引用和数字一致性检查；
2. 导师关于数据划分、公平比较、CNN 依据和现代文献的四项主要质疑均得到证据回应；
3. 三条现有实验流程被准确定位为受控、轻量和模块化比较；
4. 至少完成一个多头 CNN 对照实验或等价的系统性失败分析；
5. 所有结论与实验范围相匹配，没有过度宣称。
