## 1. 项目课题

基于开放词汇视觉语言模型引导的 2D 机器人抓取矩形检测

项目题目：采用几何与学习式抓取后端的 VLM 引导二维机器人抓取矩形检测

本项目旨在研究预训练开放词汇视觉语言模型是否可以作为机器人抓取任务中的语言条件目标定位前端，并比较不同抓取框生成后端在 2D 抓取矩形检测中的表现。具体而言，项目将 VLM 输出的目标区域分别接入传统几何后端和轻量 CNN 学习式后端，用于生成 2D 抓取矩形。项目重点是模块化 VLA 风格的抓取感知，而不是完整机器人控制或真实机械臂执行。


## 2. 项目兴趣方向

我的主要项目兴趣方向是深度学习、计算机视觉、机器人感知和视觉语言模型。我尤其感兴趣的是预训练多模态模型如何帮助机器人理解物体和场景，特别是在目标定位、目标检测和机器人抓取检测任务中的应用。

从更宽泛的角度看，本项目与具身智能相关，但硕士阶段的研究范围将聚焦在机器人系统的视觉感知部分，而不是完整的机器人控制闭环。


## 3. 适合的数据集

本项目计划主要使用 Cornell Grasping Dataset。该数据集是 2D 机器人抓取检测领域常用的学术基准数据集，包含日常物体的 RGB-D 图像以及人工标注的旋转抓取矩形。

数据集公开可获取，适合硕士项目快速开展。

该数据集在机器人抓取检测研究中使用广泛，便于与已有研究对照。

数据集中包含 2D 抓取矩形标注，适合进行量化评估。

项目不依赖真实机械臂、传感器或硬件控制，风险较低。

数据集支持项目聚焦于视觉感知、目标定位和抓取矩形预测。


## 4. 研究问题与核心目标


### 核心研究问题

预训练开放词汇视觉语言模型作为目标定位前端时，能够在多大程度上提升 2D 机器人抓取矩形检测？

预训练 VLM 或开放词汇目标检测模型能否在不进行任务特定端到端训练的情况下，通过文本提示词在 Cornell 数据集中定位目标物体？

VLM 输出的目标区域能否通过不同抓取框生成后端，例如 OpenCV 几何规则或轻量 CNN 回归网络，转换为可靠的 2D 抓取矩形？

与传统计算机视觉基线相比，VLM 引导的实验流程在抓取矩形准确率、角度误差和鲁棒性方面表现如何？当 VLM 定位可靠时，系统瓶颈是否会转移到抓取矩形生成后端？


### 拓展研究问题

如果 VLM 引导的几何流程顺利完成，项目将进一步探索 VLM 引导的 CNN 抓取后端是否可以改善手工几何后端在抓取矩形生成上的限制。VLM 少样本适应或微调保留为复杂多目标场景下的后续工作，不作为当前项目成败的核心要求。


## 5. 核心目标

整理 Cornell 数据集，解析图像和抓取标签，并可视化真实标注抓取矩形。

构建可复现的传统计算机视觉基线，包括 OpenCV、轮廓分析、PCA 和旋转边界框方法。

部署预训练开放词汇视觉定位模型，例如 Grounding DINO、OWL-ViT 或 Florence-2。

将 VLM 目标定位结果与几何抓取估计后端结合，形成完整的 VLM 引导几何抓取检测流程。

使用定位 IoU、抓取矩形 IoU、角度误差、Cornell 风格抓取成功标准和失败案例分析进行评估。

在 VLM 引导的几何流程稳定后，分析失败案例，并实现轻量 VLM 引导的 CNN 抓取回归器，用于在 VLM 裁剪区域内学习抓取矩形生成。若时间允许，再探索 GG-CNN 风格的稠密预测。


## 6. 初步方法设计

输入：Cornell 数据集中的 RGB 或 RGB-D 图像，以及描述目标物体或类别的文本提示词。

视觉语言定位：使用预训练 VLM 或开放词汇目标检测模型根据提示词识别目标物体区域。

抓取框生成后端：首先利用 OpenCV 几何规则对 VLM 目标区域进行处理并估计二维抓取矩形；随后引入轻量 CNN，在 VLM 裁剪区域内直接回归抓取矩形参数。

量化评估：将预测抓取矩形与 Cornell 人工标注进行比较，并结合定性可视化、失败案例分析以及传统计算机视觉、VLM 引导的几何后端和 VLM 引导的 CNN 后端三类方法对比。

范围控制：本项目研究的是机器人抓取感知，不是完整机器人控制系统。这样既保留技术含量，也降低硬件和控制系统带来的风险。

## 8. 风险管理与备用方案


### 主要风险

项目中风险较高的部分包括 VLM 微调、PEFT 扩展以及端到端抓取网络训练。当前实验显示 VLM 零样本定位已经较稳定，因此 VLM 微调不作为优先核心交付；端到端网络将从轻量 CNN 基线开始，降低训练和工程风险。


### 备用方案一

如果 VLM 引导的 CNN 训练效果有限，项目将聚焦于传统计算机视觉基线与零样本 VLM 引导几何流程的量化对比，并围绕失败案例分析完成论文主体。


### 备用方案二

如果 VLM 部署不稳定，项目将聚焦于可复现的传统计算机视觉基线，并在条件允许时加入轻量目标检测方法作为替代对照。

安全核心交付：在 Cornell 数据集上完成一个可复现的二维机器人抓取检测流程，包括数据处理、抓取框可视化、传统计算机视觉基线、评估指标和失败模式分析。

## 11. 实验后计划调整：VLM 引导的抓取感知与抓取框后端改进

根据当前阶段实验结果，项目计划需要进行一次合理调整。Grounding DINO 在 Cornell 数据集上使用通用提示词“small object”已经实现 885/885 的目标定位成功率，说明 VLM 负责的目标定位阶段已经足够稳定。

然而，VLM 辅助流程的最终抓取检测成功率为 649/885，即 73.33%。这说明剩余错误主要不来自目标定位，而来自 VLM 边界框之后的抓取矩形生成阶段。也就是说，当前瓶颈已经从“能否找到物体”转移为“找到物体后如何生成更准确的抓取矩形”。

因此，项目后续不再优先进行 VLM 微调。VLM 少样本适应和微调将保留为后续工作，尤其适用于更复杂的多目标、开放场景或语言指令场景。当前阶段的主要改进方向是分析 VLM 引导几何方法的失败案例，并引入 VLM 引导的 CNN 抓取后端作为新的对照和改进方案。

新的实验路线为：传统计算机视觉基线 → VLM 引导的几何后端 → VLM 引导的 CNN 后端。前两者用于证明 VLM 定位前端对几何抓取框生成有帮助；第三者用于检验学习式 CNN 后端是否能够缓解手工几何规则在抓取角度、中心位置和尺寸估计上的限制。

学习式后端将优先从轻量 VLM 引导的 CNN 抓取矩形回归开始，即输入 VLM 裁剪区域的 RGB 或 RGB-D 图像，输出中心横坐标、中心纵坐标、宽度、高度和角度。其中角度可用 `sin(2θ)` 和 `cos(2θ)` 表示，以处理平行夹爪的 180° 等价性。若时间允许，再进一步探索 GG-CNN 风格方法，输出抓取质量图、角度图和宽度图。

该调整并不偏离原计划，而是基于实验结果对研究重点进行收敛：当 VLM 零样本定位已经达到较高可靠性时，继续微调 VLM 的边际收益有限；相比之下，改进抓取矩形生成后端更能直接回应当前系统的主要误差来源。

本项目因此可表述为一个模块化 VLA 风格抓取感知研究：视觉信息来自 RGB/RGB-D 图像，语言信息来自目标提示词，动作表示则是二维抓取矩形。项目不训练完整 VLA 控制模型，而是聚焦于从 VLM 引导的感知到抓取动作表示的转换。


## 12. 2026-08-01 计划调整：分阶段完成 PyBullet 闭合、抬升与后端比较

### 12.1 目标与研究边界

Cornell 二维阶段继续保留传统 CV、VLM + 几何、VLM + 单头 CNN 和
VLM + 多头 CNN 四种方法，用于区分开放词汇定位、几何先验、学习式回归和
分头结构的作用。PyBullet 物理执行阶段不再让四种方法全部重复进入控制流程，
而是保留两个具有互补优势的最终候选：

- **VLM + 几何后端**：Cornell 成功率和平均角度误差占优；
- **VLM + 多头 CNN**：Cornell 平均 IoU 最高，中心和尺寸回归更准确。

传统 CV 只保留为无语义定位基线；单头 CNN 只保留为多头结构的受控学习式
基线。后续仿真最终目标是让几何和多头后端在相同场景、相同 RGB-D、相同
Grounding DINO 定位框、相同轨迹/控制器和相同成功判据下执行闭合与抬升，
再比较仿真抓取成功率。二维矩形成功、静态 IK 或离散碰撞通过均不得提前写成
物理抓取成功。

### 12.2 增量实施原则

物理执行按依赖关系逐级增加能力，而不是一次接入视觉、轨迹、接触和抬升。
每个阶段必须具有独立命令、独立测试、独立输出目录和机器可读 summary；只有
本阶段门控通过后才进入下一阶段。失败也必须保存失败阶段、最后有效状态、
碰撞对象或接触对象，不得只返回一个无解释的 `false`。

所有阶段共同遵守以下约束：

1. 首先使用最简单的红色方块和 PyBullet 真值世界坐标验证机器人控制，感知
   预测最后接入；这样可以将机械臂控制失败与视觉预测失败分离。
2. 手指在到达抓取高度前保持 `0.04 m` 张开；除专门闭合阶段外不得改变夹爪。
3. 继续使用当前 `5 mm/5°` 末端姿态门槛和 `2 mm` 碰撞余量；任何调整必须
   作为新的实验决策记录，不能为获得通过而静默放宽。
4. 默认从 cube 开始，cube 完整闭合和抬升通过后再扩展到 sphere，duck 最后
   处理；当前 duck 环境余量失败不阻塞最小运动控制链验证。
5. 各阶段元数据明确区分规划、实际 `stepSimulation` 执行、夹爪命令、目标
   接触和抬升，未执行的字段保持 `false`。

- 本阶段闭合后保持，不抬升；接触通过不等于抓取成功。

  `93` 步首次取得双指同时接触，末段连续保持 `121` 步，左右最大法向力为
  `20.49 N/19.15 N`。cube 最大位移 `0.0001181 m`，环境、自碰撞和非手指
  cube 接触均为零，总科学门控通过。五张图已人工确认方块仍在桌面，metadata

#### 阶段 5：真值方块抬升与保持

- 在阶段 4 的闭合状态下执行垂直抬升；冻结阶段 4 最终双指命令，不额外收紧、
  重抓或切换力控制。

  抬升终点连续保持 240 个 PyBullet 步且未从夹爪脱落。

- 只有本阶段通过，才可称为一次使用真值姿态的仿真抓取成功。

### 12.4 计划中的代码和产物边界

后续实现应在 `src/simulation/pybullet/` 中新增独立职责模块，而不把电机或
夹爪执行混入现有静态 `kinematic_audit.py`：

- `motion_control.py`：轨迹时间参数化、电机命令、逐步状态采样和到达门控；
- `gripper_control.py`：张开、闭合、双指目标接触和接触事件记录；
- `lift_control.py`：冻结双指命令下的抬升、保持、目标高度、桌面接触和相对
  漂移采样；
- `grasp_execution.py`：接近、闭合、抬升和保持状态机及分阶段结果类型；
- `run_truth_lift.py`：阶段 5 真值方块完整执行、证据写入和 CLI；
- `run_grasp_execution_study.py`：阶段选择、几何/多头公平编排、CLI 和产物写入。

对应测试放在 `tests/simulation/`，分别覆盖安全空中运动、真值 pregrasp、张开
接近、目标接触、抬升保持、失败阶段保真和两后端共同初始状态。生成产物写入
`data/processed/pybullet/grasp_execution/`，每次运行至少包含
`state_trace.csv`、`contact_events.csv`、`summary.json`、`metadata.json` 和
关键阶段图像。`data/` 继续保持 Git 忽略，项目记录只写入经过真实输出验证的
结果。

### 12.5 停止条件与论文表述

任一阶段未通过时，当前迭代停在该阶段进行根因分析，不同时实现下一阶段以
掩盖问题。即使最终未完成60次正式试验，已经通过的安全运动、目标上方到达、
垂直接近、闭合接触或真值抬升仍分别构成可报告的系统集成成果；但论文必须按
实际最远通过阶段收窄措辞。只有执行闭合、达到抬升高度并完成保持门控的试验
才能进入仿真抓取成功率分子。
