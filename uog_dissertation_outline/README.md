# UofG Dissertation Outline

This folder is based on the University of Glasgow School of Computing Science Level 4 Project LaTeX template from the provided ZIP file.

The template resources are preserved:

- `l4proj.cls`
- `fonts/`
- `images/`
- `images/CompSci_colour.pdf` for the title-page logo
- `images/uog_white.pdf` and `images/uog_white.svg`

## Main File

Compile:

```text
l4proj.tex
```
